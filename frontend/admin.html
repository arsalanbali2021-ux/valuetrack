Getting the list from IRDAI

  1. Open irdai.gov.in/health-insurance-products in your browser.
  2. Filter by year or insurer if you want, and show as many rows per page as it allows.
  3. Save the page with Ctrl+S ("Webpage, HTML only"), or select the rows in the table and copy them.
  4. Upload the file (a CSV works too), or paste the rows into the box, then press Import.

IRDAI's robots.txt doesn't allow bots, so ValueTrack never downloads the list itself. Importing again is safe. Products are matched on UIN and updated.
